# 3D 离线看图

适合手机和电脑浏览器使用的三维模型查看器，所有模型都只在本机浏览器中处理，不会上传到服务器。

## 支持的文件

- STEP / STP
- STL
- OBJ

## 主要功能

- 单指或鼠标旋转模型
- 双指或滚轮缩放
- 平移和自动适合窗口
- 整体颜色切换
- 标准、哑光、金属、高光、结构线材质
- 实体和线框显示
- X、Y、Z 轴朝上及每次旋转 90°
- 关闭模型并释放临时内存
- 安装到 iPhone 主屏幕后离线使用

## 在线使用

网站由 GitHub Pages 自动发布。第一次打开时需要联网；显示“离线可用”后，可从 Safari 添加到 iPhone 主屏幕并离线打开。

## 隐私

导入的三维文件不会离开设备。解析、显示和颜色调整都在浏览器中完成。

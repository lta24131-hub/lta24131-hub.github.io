# 3D 离线看图

适合手机和电脑浏览器使用的三维模型查看器。普通模型可完全离线打开；大型 STEP 既可以先在手机本地尝试，也可以选择云端生成轻量外观模型。

## 支持的文件

- STEP / STP
- STL
- OBJ
- GLB
- 3MF

## 主要功能

- 单指或鼠标旋转模型
- 双指或滚轮缩放
- 平移和自动适合窗口
- 整体颜色切换
- 标准、哑光、金属、高光、结构线材质
- 实体和线框显示
- X、Y、Z 轴朝上及每次旋转 90°
- 关闭模型并释放临时内存
- 大型 STEP 可选择正常本地打开、极简本地预览或云端轻量化
- 极简本地预览会降低曲面精细度并自动关闭高开销的结构线
- 云端自动删除内部不可见零件，仅保留外观
- 安装到 iPhone 主屏幕后离线使用

## 在线使用

网站由 GitHub Pages 自动发布。第一次打开时需要联网；显示“离线可用”后，可从 Safari 添加到 iPhone 主屏幕并离线打开。

## 本地与云端处理

普通文件和“手机直接尝试”模式只在浏览器中处理，不会上传。

只有用户明确选择“云端快速打开”时，大型 STEP 才会进入私有临时存储，并临时复制到 GitHub 托管的转换运行器处理。文件不会写入 GitHub 仓库：原始图纸在完成或失败后删除，生成的轻量模型在手机成功打开后删除；异常残留也会由定时清理移除。

# 3D 离线看图

适合手机和电脑浏览器使用的三维模型查看器。选择文件后自动本地打开，大型 STEP 边读边显示，不再选择读取方式。

## 支持的文件

- STEP / STP
- STL
- OBJ
- GLB
- 3MF

## 主要功能

- 单指或鼠标旋转模型
- 双指或滚轮缩放
- 平移和自动适合窗口
- 整体颜色切换：默认中性深灰，提供石墨灰、柔和灰、灰蓝、灰绿、暖灰、灰紫等低饱和度配色
- 标准、哑光、金属、高光材质，结构线可独立叠加
- 实体和线框显示
- X、Y、Z 轴朝上及每次旋转 90°
- 关闭模型并释放临时内存
- 大型 STEP 自动按曲面分批读取，保持原装配位置；跳过每批暂时没有曲面的空部件引用，减少重复解析，不降低精度或删除零件
- 可停止读取并保留已显示部分；未读完时明确标注“尚未完整”
- 读取时暂停结构线生成，完成后可开启
- 复用解析器、只预备下一批数据、仅在画面变化时绘制，降低重复开销
- 安装到 iPhone 主屏幕后离线使用

## 在线使用

网站由 GitHub Pages 自动发布。第一次打开时需要联网；显示“离线可用”后，可从 Safari 添加到 iPhone 主屏幕并离线打开。

## 文件隐私与限制

当前导入流程只在浏览器中处理文件，不会上传，也不会自动恢复旧的云端任务。用户图纸和生成的模型不写入 GitHub 仓库。

首次打开需联网缓存程序，此后支持离线导入。实际速度和可打开的复杂度取决于设备、曲面数量及内存，不保证任意大文件均可打开。未采用支持分批的曲面表示时，会自动使用普通读取。
